# مهارت‌های طراحی بصری شیا آرتس

مجموعه‌ای از مهارت‌های شواهد‌محور برای خلق طراحی‌های اصیلِ مذهبی و فرهنگی فارسی، بر پایهٔ مطالعهٔ عمومی و منبع‌دار از [کانون هنر شیعی](https://shiaarts.ir/).

> این پروژه یک سیستم دستورالعمل و پژوهش است؛ مدل آموزش‌دیده یا fine-tuned نیست.

## محتویات

- `skills/shiaarts-graphic-designer/`: مهارت پایهٔ طراحی، روند تولید، کنترل تایپوگرافی فارسی/عربی، بررسی متن‌های مقدس، مرزهای حقوقی و قرارداد شواهد.
- `skills/shiaarts-artist-*/`: برای هر هویت/نام ثبت‌شدهٔ هنرمند یک مهارت جداگانه. هر پروفایل میزان شواهد بصری خود را اعلام می‌کند و برای آثار بررسی‌نشده سبک جعل نمی‌کند.
- `research/`: metadata آثار، فهرست هنرمندان و taxonomy، صف بررسی تصویری، دفتر پوشش و یادداشت‌های انتساب/منبع.
- `tools/`: خزندهٔ عمومیِ قابل‌ادامه، بسته‌بندی مهارت‌ها و ابزار refresh.

## وضعیت شواهد

این مخزن یک snapshot پژوهشیِ مرحله‌ای است. پیش از هر ادعای جامعیت، `research/coverage.json` و `research/visual-review-queue.jsonl` را بررسی کنید.

- دریافت تصویر، OCR، نام فایل یا وجود نام در taxonomy به‌تنهایی بررسی بصری محسوب نمی‌شود.
- برچسب موضوعی صفحه یا تاریخ انتشار، به‌تنهایی مناسبت یا تاریخ سفارش اثر را ثابت نمی‌کند.
- مهارت‌های هنرمندان فقط زمانی ادعای سبک می‌کنند که برای آثار مرتبط مشاهدهٔ بصری مستند وجود داشته باشد.

## نصب در Codex

پوشه‌های زیر `skills/` را در `%USERPROFILE%\.codex\skills\` کپی کنید. سپس برای مهارت پایه از `$shiaarts-graphic-designer` استفاده کنید و مهارت هنرمند موردنظر را فقط با توجه به وضعیت شواهد همان پروفایل فراخوانی کنید.

## ادامهٔ ممیزی

خزنده به `robots.txt` احترام می‌گذارد، از درخواست‌های عمومی و ترتیبی استفاده می‌کند، حداقل فاصلهٔ درخواست‌ها را با قفل پایدار کنترل می‌کند و URLهای آرشیوی `/file/.../download` را فقط به‌صورت metadata ثبت می‌کند.

تصاویر اصلی، cache محلی، SQLite، snapshotهای خام HTML و فایل‌های دانلودی منبع در مخزن عمومی قرار نگرفته‌اند. برای فرمان‌های ادامهٔ کار، `research/README-fa.md` را بخوانید.

## حقوق و انتساب

این مخزن مجوز عمومی برای فایل‌های آثار شیا آرتس یا آثار هنرمندان صادر نمی‌کند. اخطار اختصاصی هر اثر، برای استفادهٔ اقتصادی، بازتولید و بازنشر، ذکر منبع و اجازهٔ صاحب حق را لازم می‌داند.

مهارت‌ها برای خلق آثار جدید بر پایهٔ اصول مشاهده‌شده هستند؛ از کپی‌کردن layout کامل، امضا، واترمارک یا القای تأیید هنرمند خودداری کنید.

برای جزئیات بیشتر دربارهٔ حقوق داده، `DATA-RIGHTS.md` را ببینید.
